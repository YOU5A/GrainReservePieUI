## ✨ 特性

- 🎨 **全新 UI 设计** — 彻底重构 Minecraft 基岩版界面，简洁现代
- 🧩 **多框架集成** — 融合 RainbowPieUI、MintUI、Minthawthorn、网易模块
- 🏗️ **模块化架构** — 子包系统，按需加载 FPS 显示等扩展功能
- 🖼️ **自定义主题** — 丰富的主题和图标可选
- 🎵 **音乐播放器** — 内置游戏音乐播放器
- 🧭 **方向 HUD** — 优化游戏内方向指示
- ⚡ **性能优化** — 优化脚本，提升运行效率

---

## 📦 安装

1. 下载最新的 .mcpack 文件
2. 双击文件导入 Minecraft
3. 在「设置 → 全局资源」中激活 **GrainReserve Pie UI**
4. 在设置中选择所需的子包（FPS 模块等）

## 🧱 项目结构

`	ext
GrainReservePieUI/
├── manifest.json          # 资源包清单
├── pack_icon.png          # 资源包图标
├── ui/                    # UI 定义 JSON
│   ├── RainbowPieUI/      #   RainbowPie 核心框架
│   ├── MintUI/            #   Mint 对话框组件
│   ├── .Minthawthorn/     #   HUD 扩展
│   └── netease/           #   网易版 UI
├── textures/              # 贴图资源
├── animations/            # 动画定义
├── scripts/               # .ml 优化脚本
├── subpacks/              # 子包（FPS / 资源包开关）
├── models/                # 模型文件
├── sounds/                # 音效
└── fonts/                 # 字体
`

## ⚙️ 子包说明

| 子包 | 功能 |
|---|---|
| **FPS Modules** | 屏幕顶部显示实时帧率 |
| **Resource Pack Closure** | 关闭本包以加载其他资源包 |
| **Resource Pack Opening** | 加载默认 UI 资源包 |
