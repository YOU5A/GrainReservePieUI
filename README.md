## ✨ 特性

- 🎨 **全新 UI 设计** — 彻底重构 Minecraft 基岩版界面，简洁现代
- 🧩 **多框架集成** — 融合 RainbowPieUI、MintUI、Minthawthorn、网易模块
- 🏗️ **模块化架构** — 子包系统，按需加载 FPS 显示等扩展功能
- 🖼️ **自定义主题** — 丰富的主题和图标可选
- 🎵 **音乐播放器** — 内置游戏音乐播放器
- 🧭 **方向 HUD** — 优化游戏内方向指示
- ⚡ **性能优化** — 优化脚本，提升运行效率

## 📦 安装

1. 下载最新的 .mcpack 文件
2. 如果是 7z 格式请修改后缀为 .mcpack
3. 双击文件导入 Minecraft
4. 在「设置 → 全局资源」中激活 **GrainReserve Pie UI**
5. 在设置中选择所需的子包（FPS 模块等）

---

## ⚙️ 子包说明

| 子包 | 功能 |
|---|---|
| **FPS Modules** | 屏幕顶部显示实时帧率 |
| **Resource Pack Closure** | 关闭本包以加载其他资源包 |
| **Resource Pack Opening** | 加载默认 UI 资源包 |
